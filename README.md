# HEXFRONT ／ 現代戦線 ／ 现代战线

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

ヘックス（六角形）マスの上で実在の現代兵器を動かして陣地を奪い合う、ターン制の陣取りシミュレーション。
ブラウザだけで動きます。**ファイルは `index.html` 1つ。サーバーもライブラリもネットワークも不要**（オフラインで動きます）。

- ドット絵のスプライト、地形、効果音とBGMはすべてコード内で生成します（画像ファイル・音声ファイルなし）
- 画面は横長前提。スマホは横向きでプレイ（縦向きの場合は注意表示、そのまま続行もできる）
- 言語：日本語 / English / 简体中文（タイトル画面または右上のボタンで切替、設定は保存される）
- 効果音とBGM：WebAudioで合成。「設定」でそれぞれON / OFFを切り替え、保存できます。BGMは初回操作後に再生されます。右上のボタンは効果音のみ切り替えます
- セーブ：ブラウザの localStorage に自動保存（「中断」またはターン終了のたびに保存、タイトル画面から「continue」）

## 遊び方

### 勝利条件
1. **敵本営（HQ）を占領する** … 占領には3回（3マーカー）必要。占領中にHQは反撃（20ダメージ）してくる
2. **敵の壊滅** … 敵が部隊ゼロ・収入源ゼロ・最低コストの部隊も買えない状態
3. **ターン制限到達時はスコア判定**（資金・残存部隊の価値・占領地の収入・本営を評価）。最終ターンは双方が行動した後に判定し、同点なら先手の勝利

### 1ターンの流れ
1. 自分の部隊をタップ／クリック → 緑のマスに移動、敵をタップで攻撃（攻撃前に被害予測ダイアログが出る）
2. 都市・農場・工場・飛行場・補給拠点を歩兵などで占領すると**収入**が増える
3. 収入で**工場／飛行場から新しい部隊を生産**（生産枠＝上限あり）
4. 「ターン終了」→ 敵AIが動く

### 補給と弹药
- 味方の補給拠点（都市・農場・補給基地など）の上または隣で補給（燃料・弹药の再充填）
- トラックの隣でも補給できる。燃料切れは身動きが取れず、弹药切れは攻撃不可
- 自給自足の部隊（歩兵・機関銃・対戦車ミサイルなど）は弹药が無限

### 部隊（実在兵器、17種）
歩兵（M16小隊／M240機関銃／Javelin対戦車ミサイル／工兵／M939トラック／M113装甲兵員車／
M2ブレー德利／M1A2エイブラムス／PzH2000／M270 MLRS／M163バルカン／MIM-104パトリオット／
CH-47／MQ-9／AH-64／M142 HIMARS／AEW&C）。
陸上・航空の2区分、歩兵・_SOFT（軽装甲）_・装甲・航空の4クラスで相性関係があり、
射程・地形防御・森林・市街地・丘・山・河・橋・フェリーなどが戦闘に影響します。
上位兵器は**戦域を進めるほど解放**される（武器図鑑にロック表示）。

### 操作方法
| 操作 | スマホ（横向き） | PC |
|---|---|---|
| 部隊を選択／移動／攻撃 | タップ | クリック |
| 地図のスクロール | ドラッグ | ドラッグ／ホイール |
| ズーム | ピンチ | ホイール、または ＋／－／FIT ボタン |
| 取り消し | 下部の「やめる」 | Esc |
| 1ターンのやり直し | 下部の「戻す」 | 同 |

画面下部にコマンド、上部に資金・ターン・部隊数、左下に戦闘ログ、右上に効果音／言語／メニュー。
部隊上の英字は兵種を表す略号で、タップした情報欄や兵器図鑑で名前を確認できます。小さい場合は拡大してください。
部隊を選択していない状態で地形をタップすると、地形の効果や陸上部隊の移動コストを確認できます（味方の工場・飛行場は生産画面が開きます）。

## 使い方（プレイ開始）

1. `index.html` をブラウザに開く（ダブルクリックでOK。スマホならファイルを転送して開く）
2. タイトル画面で「新しい作戦」→ ステージ選択 → 「はじめる」
3. 途中で閉じても大丈夫。再度開けば「continue」で続きから

保存先（ブラウザの localStorage）:
- `hexfront.save.v1` … 進行中の1ゲーム
- `hexfront.profile.v1` … 言語・効果音・BGM・難易度・最高スコア・解放済みステージ

ブラウザのサイトを削除するとセーブも消えます。他機種への引き継ぎには、同じブラウザ／同じファイル名で開いてください。

## 開発・ビルド・テスト

```
hexfront/
  index.html          最終成果物（Parts を連結したもの）
  build.ps1           parts/ を連結して index.html を作る
  parts/              p00_head.html, p01_core, p02_i18n, p03_data,
                      p04_stages, p05_rules, p06_ai, p07_render,
                      p08_ui, p09_audio, p10_main, p99_foot
  tests/
    logic-test.js     DOM不要のロジックテスト（六角計算・規則・AI自己対戦など）
    browser-test.js   Headless Chrome（CDP）でUI・操作・描画・スマホ画面を検証
    audio-test.js     音声のスケジューリングと設定の互換性を検証
    shots/            browser-test が書き出すスクリーンショット
```

```powershell
# ビルド（Parts → index.html）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File build.ps1

# テスト（約300項目のロジック → 約60項目のブラウザ）
node tests/logic-test.js
node tests/audio-test.js
node tests/browser-test.js
```

- `browser-test.js` はヘッドレスChromeをCDPで制御します（npm不要、Node 24の `WebSocket`/`fetch` を使用）。
  Chromeのパスは既定で `C:\Program Files\Google\Chrome\Application\chrome.exe`。
- デバッグモード：`index.html?debug=1` で資金チート・ターン自動化などのテストフック（`HF.ui.dbg.*`）が有効になります。

### 実装メモ
- 六角グリッドは pointy-top の odd-r オフセット。`HF.axial` / `HF.DIRS` が正しさと性能の両輪
- 戦闘の当たり判定は `HF.hash01` による決定論的ロール。攻撃予測のダイス目が実戦闘と一致する
- 全スプライトはASCIIビットマップ（`HF.ART`）＋パレット（`HF.PAL`）で定義し、オフスクリーンに焼き付けて nearest で描画
- AIは脅威フィールド・補給フィールド・敵HQへの圧力をキャッシュして評価（大地図でも1ターン数十ms）

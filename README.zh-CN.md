# HEXFRONT ／ 现代战线

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

这是一款回合制六角格战略游戏：指挥现代军事单位争夺阵地。游戏完全在浏览器中运行。**游戏只有一个
`index.html` 文件，无需服务器、外部库或网络连接**，也可以离线游玩。

- 像素风单位、地形、音效与背景音乐均由代码生成（无需图片或音频文件）
- 游戏适合横屏。手机建议横屏游玩；竖屏时会显示提示，但仍可继续
- 语言：日语 / 英语 / 简体中文（可在标题画面或右上角按钮切换，选择会被保存）
- 音效和背景音乐由 WebAudio 合成，可在设置中分别开关并保存；背景音乐在首次操作后播放，右上角按钮仅控制音效
- 部队上的字母为兵种代号，可点击部队或在图鉴中查看名称；太小时可放大。未选中部队时点击地形可查看效果与地面移动消耗（己方工厂和机场会打开生产界面）
- 使用浏览器 localStorage 自动保存（中断游戏或结束回合时保存，可在标题画面选择“继续”）

## 游戏玩法

### 胜利条件
1. **占领敌方总部（HQ）**：需要3格占领进度。占领期间总部会反击，造成20点伤害。
2. **击败敌军**：敌方没有部队和收入来源，并且无力购买最便宜的部队。
3. **达到回合上限时按分数判定胜负**（资金、残存部队价值、占领地收入和本部）。双方完成最后一回合后判定，平分时先手获胜。

### 回合流程
1. 点击或轻触己方部队。移动到绿色格子，或选择敌军进行攻击（攻击前会显示伤害预测）。
2. 使用步兵等可占领单位占领城市、农场、工厂、机场和补给站，以增加收入。
3. 使用收入在工厂和机场生产新部队（生产位置数量有限）。
4. 选择“结束回合”，由敌方 AI 行动。

### 补给与弹药
- 在己方补给地点（如城市、农场或补给站）所在格或相邻格补充燃料和弹药。
- 补给卡车也可以为相邻单位补给。燃料耗尽后无法移动，弹药耗尽后无法攻击。
- 步兵、机枪和反坦克导弹小组等自给型单位拥有无限弹药。

### 部队
共有17种现实中的单位：步枪班（M16）、M240机枪、标枪反坦克导弹小组、工兵、M939卡车、M113装甲输送车、
M2布雷德利、M1A2艾布拉姆斯、PzH 2000、M270 MLRS、M163火神、MIM-104爱国者、CH-47、MQ-9、AH-64、
M142 HIMARS、预警与控制飞机（AEW&C）。

单位分为陆军和空军，并按类型分为步兵、_SOFT_（轻装甲）、装甲和航空四类。兵种克制、射程、地形防御，
以及森林、城市、丘陵、山地、河流、桥梁和渡轮都会影响战斗。
随着战役推进，可以解锁更先进的单位；图鉴会显示尚未解锁的单位。

### 操作方式
| 操作 | 手机（横屏） | 电脑 |
|---|---|---|
| 选择／移动／攻击部队 | 轻触 | 点击 |
| 移动地图 | 拖动 | 拖动／滚轮 |
| 缩放 | 双指捏合 | 滚轮或 ＋ / － / FIT 按钮 |
| 取消 | 底部“取消”按钮 | Esc |
| 撤销当前回合 | 底部“撤销”按钮 | 同左 |

命令位于底部，资金／回合／部队数量位于顶部，战斗日志位于左下角，音效／语言／菜单位于右上角。

## 开始游戏

1. 使用浏览器打开 `index.html`（双击即可；手机上可先传输文件再打开）。
2. 在标题画面选择“新作战”，选择关卡，然后选择“开始”。
3. 即使中途关闭游戏，再次打开后也可选择“继续”接着游玩。

存档保存在浏览器 localStorage 中：
- `hexfront.save.v1` — 当前游戏
- `hexfront.profile.v1` — 语言、音效、背景音乐、难度、最高分和已解锁关卡

清除浏览器网站数据也会删除存档。若要在其他设备上继续游戏，请使用相同的浏览器和文件名。

## 开发、构建与测试

```text
hexfront/
  index.html          最终游戏文件（由多个部件合并而成）
  build.ps1           将 parts/ 合并为 index.html
  parts/              p00_head.html, p01_core, p02_i18n, p03_data,
                      p04_stages, p05_rules, p06_ai, p07_render,
                      p08_ui, p09_audio, p10_main, p99_foot
  tests/
    logic-test.js     无需 DOM 的逻辑测试（六角格计算、规则、AI 自我对战等）
    browser-test.js   使用无头 Chrome（CDP）测试界面、操作、渲染和手机画面
    audio-test.js     测试音频调度与设置兼容性
    shots/            browser-test 生成的截图
```

```powershell
# 构建（Parts → index.html）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 测试（约300项逻辑测试，然后约60项浏览器测试）
node tests/logic-test.js
node tests/audio-test.js
node tests/browser-test.js
```

- `browser-test.js` 通过 CDP 控制无头 Chrome（无需 npm；使用 Node 24 的 `WebSocket`／`fetch`）。
  默认 Chrome 路径为 `C:\Program Files\Google\Chrome\Application\chrome.exe`。
- 调试模式：打开 `index.html?debug=1`，启用资金作弊、回合自动化等测试钩子（`HF.ui.dbg.*`）。

### 实现说明
- 六角网格使用 pointy-top odd-r 偏移坐标。`HF.axial` / `HF.DIRS` 兼顾正确性和性能。
- 战斗通过 `HF.hash01` 进行确定性判定，因此攻击预测与实际战斗结果一致。
- 单位图像使用 ASCII 位图（`HF.ART`）和调色板（`HF.PAL`）定义，在离屏画布中绘制并以最近邻方式缩放。
- AI 会缓存威胁、补给和敌方总部压力场；即使在大型地图上，每回合也只需数十毫秒。
